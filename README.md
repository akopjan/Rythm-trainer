# Rythm-trainer

Локальный тренажёр ритма для баяна, других мелодических инструментов, ударных и проверки с клавиатуры. Приложение находится в одном файле `index.html`; сборка и внешние библиотеки не нужны.

## Запуск

1. Откройте `index.html` в современном браузере.
2. Выберите BPM, размер **3/4** или **4/4**, цикл из **1–2 тактов** и сетку **1/4**, **1/8** или **1/16**. BPM задаёт темп четвертных долей.
3. Нажмите **Start** и разрешите доступ к микрофону. Для баяна по умолчанию выбран режим «Баян / мелодический инструмент».
4. Играйте в выбранную сетку. На графике отрицательное отклонение означает раньше, положительное — позже.

Для проверки с клавиатуры отключите «Микрофон», нажмите Start и используйте **Пробел**. **Enter** переключает клетку рисунка, если на ней стоит фокус. Stop закрывает доступ к микрофону; новый Start начинает новую историю результатов.

Можно открыть приложение через постоянный локальный адрес. В терминале из папки проекта выполните:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Затем откройте [http://localhost:8000/](http://localhost:8000/). Этот вариант полезен для стабильного адреса и хранения настроек. Сервер остановится после Ctrl+C.

## Барабаны и метроном

Рисунок барабанов изначально пустой. Включайте клетки для бочки, малого барабана, хэта и тарелки. У каждого инструмента слева есть отдельный переключатель и громкость. Выключение инструмента сохраняет его рисунок. «Громкость ритма» регулирует общий уровень звука.

**Метроном** — отдельный источник щелчков по четвертным долям, с акцентом в начале такта. Он не добавляет скрытые удары хэта на восьмых. Его можно выключить переключателем сверху и настроить через «Громкость метронома» в настройках звука.

## Точность и задержка

«Автонормализация» включена по умолчанию. Она подбирает поправку по круговой медиане недавних атак, учитывая переход через соседнюю линию сетки. Первичный подбор требует минимум **9 атак**, охватывающих хотя бы **один такт**. Затем поправка плавно следует за изменениями; для дальнейшей оценки нужно окно минимум в два такта. Используются до 48 последних атак за окно не короче 12 секунд или трёх тактов. Если атаки слишком разбросаны, поправка остаётся прежней.

Первичный подбор центрирует уже собранные атаки. Последующая автоподстройка влияет на новые атаки и сохраняет результаты прошлых тактов. Кнопка **«Нормализовать»** вручную пересчитывает всю историю относительно общей медианы. Автонормализацию можно выключить и задать фиксированную поправку вручную.

По атаке инструментом нельзя отдельно определить задержку оборудования и устойчивое смещение вашей игры: автоматическое центрирование учитывает оба эффекта. Для независимого замера используйте **«Измерить задержку»**: не играйте во время восьми щелчков, дайте микрофону услышать колонки или поднесённый к нему наушник того же устройства, с которым тренируетесь. Поправкой становится медиана задержек услышанных щелчков; рядом показывается среднее абсолютное отклонение. Постоянная поправка не устраняет случайное плавание задержки.

Оценка ошибки использует линейные отклонения:

- **Средняя ошибка по модулю** — среднее расстояние обнаруженных атак от ближайшей линии сетки, в миллисекундах.
- **Разброс** — среднее абсолютное отклонение от медианы.
- **В допуске** — доля обнаруженных атак в установленном диапазоне ±мс.
- **Медианное смещение** — типичное раннее или позднее попадание.

Таблица **«Ошибка по тактам»** показывает каждый такт, число атак, среднюю ошибку по модулю, медиану и попадания в допуск. Самый неточный такт выделяется для сравнения. При цикле из двух тактов дополнительно видно место такта в рисунке.

Микрофон определяет начало и смену звука, а не высоту ноты или инструмент. Пропущенные ноты не входят в статистику обнаруженных атак. Если тихие атаки пропадают, снизьте «Порог атаки»; при ложных срабатываниях поднимите его. Наушники уменьшают попадание ритма в микрофон. Для колонок доступна отдельная калибровка фона на три цикла без вашей игры.

## Сохранение настроек

Параметры, включение и громкость каждого барабана, рисунок и текущая поправка автоматически сохраняются в `localStorage` этого браузера. История атак, аудио и разрешение микрофона не сохраняются. Аудио обрабатывается локально, не записывается и никуда не отправляется.

Для файловых адресов `file://` поведение `localStorage` зависит от браузера. После переноса HTML в другую папку сохранённые параметры могут оказаться недоступны; это ограничение описано в [документации MDN](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage). Для переносимой копии:

1. Нажмите **«Настройки в файл»** и сохраните `rhythm-settings.json` рядом с HTML или в своей папке.
2. На другом устройстве или после перемещения HTML нажмите **«Загрузить настройки»** и выберите этот JSON-файл. Перед импортом остановите тренировку.

`default-settings.json` содержит начальные значения и пустой рисунок. Его можно загрузить той же кнопкой. Личный `rhythm-settings.json` исключён из Git, чтобы настройки оставались на вашем устройстве.

## Автоматические проверки

Для запуска проверок нужен установленный Deno. Из папки проекта:

```sh
deno run --allow-read tests/controls-extended.mjs index.html
deno run --allow-read tests/controls-persistence.mjs index.html
deno run --allow-read tests/adaptive-helper.mjs index.html
deno run --allow-read tests/median-helper.mjs index.html
deno run --allow-read tests/median-probe.mjs index.html
deno run --allow-read tests/bayan.mjs index.html
deno run --allow-read tests/baseline.mjs index.html
deno run --allow-read tests/settings-helper.mjs index.html
```

Проверки используют модели браузера и синтетический звук. Они проверяют расчёты, управление, сохранение настроек и распознавание атак; акустический тракт конкретного микрофона и аудиоустройства проверяется во время реальной игры.
